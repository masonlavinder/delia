# future_plans

Designs for things not built yet. One file per idea: what it is, why this
approach over the alternatives, what would actually break, and the phases to
get there. A plan lives here until it's built — then it becomes code plus an
`instructions/` runbook, and the plan is deleted.

Not a TODO list and not a place for architecture — that's `CLAUDE.md`. If it's
small enough to just do, do it.
