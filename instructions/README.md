# instructions

Short how-to docs for things done rarely enough to forget. One file per task,
written to be followed step by step months from now with no context loaded.

| Doc | What it covers |
|---|---|
| [`reaching-the-pi.md`](reaching-the-pi.md) | Ping / SSH / find it on the network; what to check when it's not answering; renaming it |
| [`wifi-new-network.md`](wifi-new-network.md) | Move the Pi to a new WiFi network, or update the password on the current one |

Not the place for architecture or conventions — those live in `CLAUDE.md`,
`matrix/README.md`, and `web_app/README.md`. Hardware build/repair is
`matrix/raspberry_pi/led-matrix-setup.md`.

## Adding one

Drop in a new `.md`, add a row above. Keep it procedural: what you're trying to
do, the commands in order, and how to tell it worked. Note the failure you
actually hit — that's the part you won't remember.
